# Práctica No. 6: Diagrama de Secuencia de Pantallas (Sketches)

## Descripción

Esta práctica presenta un diagrama de secuencia de pantallas (*sketches*) para representar el flujo de navegación de una aplicación móvil inspirada en WhatsApp. El proyecto reúne en un solo archivo HTML dos variantes independientes: WhatsApp normal y WhatsApp Business.

El propósito es visualizar las pantallas principales de cada variante y comprender cómo una persona usuaria avanza de una pantalla a otra para realizar acciones comunes.

## 2. Objetivo

Diseñar y representar, mediante bocetos de baja fidelidad y un diagrama de secuencia, la navegación entre las pantallas principales de WhatsApp normal y WhatsApp Business.

## 3. Alcance de la práctica

La página permite seleccionar una de las dos variantes y explorar sus pantallas, transiciones y acciones representadas. La finalidad es académica y visual; no es una aplicación oficial de WhatsApp ni se conecta con sus servicios reales.

### WhatsApp normal

Se representan flujos relacionados con la configuración inicial y la mensajería personal, como la bienvenida, el registro o verificación del número, la lista de chats, la selección de contactos, la conversación y la recepción de mensajes.

### WhatsApp Business

Se representan flujos orientados a la comunicación comercial, como el perfil del negocio, el catálogo de productos, las conversaciones con clientes, las respuestas rápidas, las etiquetas y las herramientas de actividad.

## Requisitos

- Un navegador web actualizado, como Google Chrome, Microsoft Edge o Firefox.
- No requiere instalar dependencias.
- No requiere conexión a una base de datos ni ejecutar un servidor.

## Cómo ejecutar

1. Descarga el archivo `index.html`.
2. Guarda el HTML y este README en la misma carpeta, si deseas mantener la documentación junto al proyecto.
3. Abre el archivo HTML con doble clic o arrástralo a una ventana del navegador.
4. Utiliza los controles superiores para cambiar entre **WhatsApp normal** y **WhatsApp Business**.
5. Explora las pantallas, sus transiciones y las opciones de visualización disponibles.
6. Si necesitas entregar la práctica en papel o PDF, utiliza la opción de impresión del navegador o la función de impresión disponible en la página, si está visible.

## Contenido de la práctica

### WhatsApp normal

Representa el flujo de uso personal, incluyendo pantallas de acceso y verificación, lista de conversaciones, selección de contactos y conversación.

### WhatsApp Business

Representa un flujo comercial con elementos como perfil de negocio, catálogo, conversaciones con clientes y herramientas para organizar o agilizar la atención.

## Tecnologías

- HTML5 para la estructura.
- CSS3 para los estilos y la adaptación a diferentes tamaños de pantalla.
- JavaScript para los controles e interacciones.

Todo el contenido está integrado en un único archivo HTML.

## Limitaciones

Esta práctica es una maqueta académica. No se conecta a los servicios oficiales de WhatsApp, no autentica números telefónicos, no guarda conversaciones en un servidor y no envía mensajes reales. Las pantallas representan un ejemplo de navegación.
